零、先立一个总观念：嵌套循环到底在干嘛

打个比方：嵌套循环像一块钟表 —— 外层像分针，内层像秒针。分针（外层 i）每走一格，秒针（内层 j）就整整跑完一圈。代码里就是：外层每取一个值，内层把自己的整个 range 从头到尾跑一遍。

写代码前先回答一个问题：「第 i 行应该打几个式子？」99 乘法表第 1 行 1 个、第 2 行 2 个……第 i 行 i 个。所以内层要跑 i 次 → range(1, i + 1)。想清楚数量关系，代码自然就出来了。

一、阶梯乘法表

需求：第 i 行输出 i 个乘法式子，共 9 行，呈阶梯状：

1x1=1
1x2=2 2x2=4
1x3=3 2x3=6 3x3=9
……

参考代码：

for i in range(1, 10):          # 外层：行号 i 从 1 到 9
    for j in range(1, i + 1):      # 内层：第 i 行打 i 个式子
        print(f"{j}x{i}={i*j}", end="  ")   # 打完不换行，用两个空格隔开
    print()                          # 一行结束，手动换行

三个必须想明白的点：

  1. 为什么是 range(1, i+1) 而不是 range(1, i)？
    因为 range 含头不含尾。要打到 i，终点就必须写到 i+1。写成 i，每行会少最后一个式子（第 9 行只有 8 个）。
  2. end=" " 是干什么的？
    print 像一台盖章机：默认每盖一个章（输出一项），就自动换一行纸。end=" " 是把"换行"这个默认动作改成"盖两个空格"，于是同一行的式子们才能排在一排。
  3. 每行末尾的 print() 是干什么的？
    内层结束后，这一行还缺一个换行。空 print() 就是只盖一个"换行"章，不盖别的。忘了它，45 个式子会全部糊在一行里。
小实验（当场敲一遍）： 
print("A", end="")
print("B")
print()
print("C")
输出三行：第一行 AB（end 把换行吞了）、第二行空行（空 print 只换行）、第三行 C。
坑：内层 print 的 end 参数只在"不想换行"时才加；行尾的 print() 属于外层循环体（缩进 4 空格，和内层 print 对齐以外）—— 缩进错一层，程序就变样。

二、猜数字 random 版

需求：程序心里想一个 1~100 的随机数，你来猜，程序提示"大了/小了"，猜中时报告一共猜了几次。

参考代码：

import random                            # 请 random 工具箱入场

answer = random.randint(1, 100)          # 随机答案：1~100 之间（含 1 和 100）
count = 0                                # 计数器：猜了几次，初始必须是 0

while True:                             # 永远循环，靠 break 退出
    guess = int(input("请输入你猜的数字(1-100): "))
    count = count + 1                    # 每猜一次，计数器 +1
    if guess == answer:
        print(f"猜对了！答案是 {answer}，你一共猜了 {count} 次")
        break                          # 先报告胜利，再跳出循环
    elif guess > answer:
        print("大了，往小猜")
    else:
        print("小了，往大猜")

五个必须想明白的点：

  1. random.randint(1, 100) 是什么？从 random 模块请来的工具函数，每次调用返回 1~100 的一个随机整数（两头都包含）。import random = 把工具箱请进程序。原理第 8 周讲，现在当黑盒放心用。
  2. 为什么必须写 answer =？这是你的老卡点：函数只负责算，= 才负责存。random.randint(1,100) 算出一个数，不存回变量，你就永远拿不到它。
  3. count = count + 1 累加器：你算 5050 时已经用熟的模式 —— 每次循环给自己 +1。初始值必须是 0，放循环外面。
  4. 为什么用 while True？猜几次才中，天知道。没有固定次数 → "永远循环 + 条件满足就 break"。
  5. break 的位置：在 if guess == answer 里面、打印之后 —— 先报胜利再退场。你之前把打印放到 break 后面（循环外），胜利消息就永远打不出来了。
坑：int(input(...)) 别忘 int —— input 拿到的永远是字符串，字符串和整数比大小会直接报 TypeError。另外 elif 的顺序：先判相等，再判大小，逻辑别反。

三、打印菱形

需求：n=5 时输出 9 行菱形（上半 5 行 + 下半 4 行，中间行不重复）：

····*
···***
··*****
·*******
*********
·*******
··*****
···***
····*

（· 代表一个空格）

核心认知：菱形 = 正金字塔 + 倒金字塔。先画表，后写码 —— 第 i 行 = 空格 (n-i) 个 + 星 (2i-1) 颗：

i空格数 (n-i)星数 (2i-1)那一行长什么样
141····*
233···***
325··*****
417·*******
509*********

参考代码：

n = 5
# 上半：i 从 1 长到 5，越往下空格越少、星越多
for i in range(1, n + 1):
    print(" " * (n - i) + "*" * (2 * i - 1))
# 下半：i 从 4 缩到 1 —— 从 n-1 开始，中间行不重复！
for i in range(n - 1, 0, -1):
    print(" " * (n - i) + "*" * (2 * i - 1))

四个必须想明白的点：

  1. 星数为什么是 2*i-1？菱形的每一行星数必须是奇数，且中间行（i=n）要 2n-1 颗。奇数序列 1、3、5、7、9 正好等于 2i-1。
  2. " " * (n - i) 字符串乘法：" " 乘 4 = 4 个空格。先生成缩进，再拼内容，所以这一行是字符串相加。
  3. 下半为什么从 n-1 开始？中间行（i=5，9 颗星）上半已经打过了。下半若从 n 开始，中间行打两遍，菱形中间鼓个包。从 n-1（4 颗星那行）开始缩，才对称。
  4. range(4, 0, -1) 三个参数：起点 4、终点 0（不含）、步长 -1 —— 每步往后退 1，输出 4、3、2、1。这就是倒序循环，以后倒计时、倒序输出全靠它。
选做挑战（高度由用户输入）：只改第一行，程序立刻通用： 
n = int(input("请输入菱形高度(奇数): "))
for i in range(1, n + 1):
    print(" " * (n - i) + "*" * (2 * i - 1))
for i in range(n - 1, 0, -1):
    print(" " * (n - i) + "*" * (2 * i - 1))
输入 3，输出 5 行菱形。这就是变量化的威力：写死的数字换成变量，程序从"一次性"变"通用"。

四、比三道题更值钱的东西

三道题的共同主线：先画表，后写码。
  • 乘法表：先列出「第 i 行几个式子」→ 才有 range(1, i+1)
  • 菱形：先列出「每行几个空格、几颗星」→ 才有 " "*(n-i) + "*"*(2i-1)
  • 猜数字：先列出「程序有几种状态、每种状态怎么流转」→ 才有 while True + break 的结构
代码只是表格的翻译。以后写任何循环，都先问自己：能不能把它画成一张表？能，代码就是抄表格；不能，说明还没想清楚，别急着敲键盘。

五、课堂练习（含参考答案）

练习 1：把乘法表改成「只显示偶数行」

👉 点开看参考答案 
for i in range(1, 10):
    if i % 2 != 0:          # 奇数行跳过
        continue
    for j in range(1, i + 1):
        print(f"{j}x{i}={i*j}", end="  ")
    print()

解析：% 取余数判断奇偶；continue 跳过本轮直接进下一行 —— 巩固课刚讲过，这里直接用。注意 continue 写在外层循环里，跳过的是"整行"。

练习 2：猜数字加「范围提示」

👉 点开看参考答案 
low, high = 1, 100               # 记录当前已知的答案范围
while True:
    guess = int(input(f"猜 {low}~{high} 之间的数: "))
    if guess == answer:
        print("猜对了！")
        break
    elif guess > answer:
        high = guess - 1          # 答案比猜的小，上限收紧
    else:
        low = guess + 1           # 下限收紧
    print(f"提示：答案在 {low}~{high} 之间")

解析：用两个变量追踪状态，每次猜错就收紧范围。这是"程序有记忆"的雏形 —— 和第 3 周的列表是同一个思想。

练习 3：实心三角形（菱形上半）

👉 点开看参考答案 
n = int(input("三角形高度: "))
for i in range(1, n + 1):
    print(" " * (n - i) + "*" * (2 * i - 1))

解析：菱形的一半。能写出这个，菱形就只剩"再抄一遍倒序"。

六、常见坑汇总（本课专属）

坑 1：range 终点忘 +1 —— 含头不含尾，要打到 i 就得写 i+1。这是你上周错过的点（range(1,100,7)），乘法表里又用上了。
坑 2：忘记行尾空 print() —— 45 个式子糊一行。症状好认，治法简单。
坑 3：random 的结果不存变量 —— random.randint(1,100) 算完就扔，后面永远拿不到。老规矩：函数只算，= 才存。
坑 4：菱形下半从 n 开始 —— 中间行打两遍，菱形变沙漏鼓包。记住：上半已经打过的行，下半不重复。
坑 5：break 写在打印后面 —— 先 break 后打印，胜利消息在循环外，永远不执行。先报胜利，再退场。
