一、需求拆解

  1. 输入层：input 问姓名（str）、身高（float）、体重（float）
  2. 计算层：BMI = 体重 ÷ 身高的平方，即 weight / (height ** 2)
  3. 判断层：四个区间 → 偏瘦 <18.5 / 正常 18.5~24 / 超重 24~28 / 肥胖 ≥28（中国标准），每个区间给出对应健康建议
  4. 输出层：等号线包住的"个人健康卡片"，字段对齐

二、核心代码讲解

# 输入层：float(input(...)) 从里往外读 —— 先拿到字符串，立刻转数字
name = input("请输入你的姓名：")
height = float(input("请输入你的身高（米）："))
weight = float(input("请输入你的体重（公斤）："))

# 计算层：** 是乘方，height ** 2 就是身高平方
bmi = weight / (height ** 2)

# 判断层：四个 if 用 and 卡住边界，无缝覆盖所有情况
if bmi < 18.5:
    tixing = "偏瘦"
if bmi >= 18.5 and bmi < 24:
    tixing = "正常"
# ... 24~28 超重、≥28 肥胖同理

# 输出层：round(bmi, 2) 把长小数收成两位
print(f"BMI: {round(bmi, 2)}")
print(f"体型: {tixing}")

round() 30 秒：round(数值, 位数) 四舍五入到指定位数：round(20.7475..., 2) → 20.75。塞进 f-string 的 {} 里也合法 —— 窗口里可以放任何表达式。

打磨点 1（重要）：缩进不统一 —— 部分行 3 空格、部分行 4 空格。当前恰好能跑，但风格混用是定时炸弹。规矩：Python 缩进永远 4 空格，VS Code 里按 Tab 就是 4 空格。
打磨点 2：长小数 —— BMI:20.747550193111813 → 用 round(bmi, 2) 收拾，改成 print(f"BMI: {round(bmi, 2)}")。
打磨点 3（小）：中英文混杂 —— 提示语英文、卡片中文。统一成中文，程序给谁用，提示语就说什么话。
