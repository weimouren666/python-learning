命名三条规矩：① 只能字母/数字/下划线，且不能数字开头（score2 ✓，2score ✗）；② 区分大小写，Age 和 age 是两个变量；③ 不能用关键字（class、if 等）。

风格惯例：多个单词用下划线：student_name（蛇形命名，Python 社区标准）。# 后面是注释，给人看的，Python 跳过。

四、input() 的坑 与 类型转换

最大的坑：input() 交给你的永远是字符串，哪怕你输入的是数字。因为键盘敲出来的本来就是字符。

age = input("请输入你的年龄：")
print(type(age))   # <class 'str'> ！

类型转换三兄弟：

int("18")      # → 18     字符串转整数
float("1.77")  # → 1.77   字符串转小数
str(18)        # → "18"   数字转字符串

标准用法（从里往外读：先 input 拿字符串，再转数字）：

age = int(input("请输入你的年龄："))
print(age + 1)   # 现在能做数学加法了
今晚最重要的心智模型：函数只负责"算"，= 才负责"存"。
float(high) 只是照体重秤看了一眼数字，变量纹丝不动；high = float(high) 才把新值登记回变量，完成"换血"。任何东西不经过 = 存回变量，就永远只是"看了一眼"。

五、学会读 Traceback（今晚实战两次）

TypeError: can only concatenate str (not "float") to str

三步读法：① 看最后一行 = 错误类型 + 人话原因；② 波浪线 ~~~^~~~ 标出出错的确切位置（Python 3.11+ 新功能）；③ 回到那行代码检查类型。

这句报错的意思：+ 左边是字符串时，Python 以为你要拼接，但拼接只允许两边都是字符串，混拼它拒绝猜 —— Python 3 特意不帮你自动转类型，因为它猜不起。

练习 2：input 的坑现场体验

input 问身高 → 直接 print → type() 查类型 → 转成 float 后计算 30 天后的身高（每天长高 1 厘米）。

👉 点开看参考答案 
high = input("你的身高是多少：")
print(type(high))          # <class 'str'> 亲眼确认坑
high = float(high)          # 关键：必须用 = 存回去！
print(type(high))          # <class 'float'> 换血成功
x = high + 0.3
print("30天后你的身高是", x, "米")   # 2.07（今天的课堂实录）

课堂实录：第一次写 float(1.77)（转的是字面量，不是变量）→ 第二次 float(high) 忘了 = 存回 → 两次 TypeError → 第三次成功。报错 → 读 Traceback → 修复 → 验证，这个闭环你已练熟。

八、常见坑（本课专属汇总）

坑 1：True/False 首字母必须大写 —— 写 true 直接报错，无数新手的第一次报错。
坑 2：input() 永远返回字符串 —— 要做计算必须先 int()/float() 转换。
坑 3：转换结果必须用 = 存回变量 —— float(high) 不写 high = 等于白转，变量原地不动。
坑 4：int("3.14") 会报 ValueError —— 整数容不下小数点，转小数用 float()。
坑 5：= 是赋值，== 才是比较 —— age = 18 是存值，age == 18 才是提问。
坑 6：文件模式不写 print 就没有输出 —— 交互模式的自动回显是特权，文件里没有。
小知识：Ctrl+C = KeyboardInterrupt —— 终端里的"急停按钮"，无害，变量不丢。将来跑死循环就靠它救命。
