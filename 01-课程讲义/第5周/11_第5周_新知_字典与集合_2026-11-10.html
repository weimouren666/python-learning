〇、为什么需要字典——你上周末的痛，它全治

shizhan4 里你要找"谁的均分最高"，被迫维护 names 和 averages 两个平行列表，靠下标对齐，还要 .index() 反查——累不累？

字典：直接用名字当"下标"。

平行列表方案（上周）字典方案（本周）
names[i] + averages[i] 对齐d["张伟"] 直接出 85.33
averages.index(max(...)) 反查遍历 d.items() 比大小即可

类比：列表是带编号的储物柜（只认编号），字典是手机通讯录——存的时候标好"张伟"，取的时候报名字。

一、字典四件事：建、查、改、增

stu = {"name": "魏常泽", "age": 18, "major": "大数据"}
stu["name"]        # '魏常泽'          查：方括号里放 key
stu["age"] = 19    #                   改：覆盖
stu["city"] = "石家庄"  #             增：key 不存在就新建
len(stu)           # 4                 几对键值
坑 1：查不存在的 key 直接 KeyError。安全取法：stu.get("phone", "没填") —— 没有就返回你给的默认值，不炸。
坑 2：key 和 value 是两个东西——"age" 是钥匙（通常是字符串），19 是盒子里的值。取值永远 d[key]，不是 d[value]。

二、遍历：.items() 一次给一对

for k, v in stu.items():
    print(k, ":", v)          name : 魏常泽 / age : 19 / ...

和 enumerate 的解包一个手感——两个变量接一对。只要钥匙：for k in stu:；只要值：for v in stu.values():

in 判断的是钥匙在不在："age" in stu → True。

三、集合 set：天生的去重机

nums = [1, 2, 2, 3, 3, 3]
unique = set(nums)     # {1, 2, 3}      自动去重，无顺序
"a" in unique          # 快速判断成员

上周 shizhan4 的 if name not in failed 判重，本质就是在手动模拟集合的本职工作。集合三大用途：去重、成员判断、算交集并集（a & b、a | b，后面项目见）。
