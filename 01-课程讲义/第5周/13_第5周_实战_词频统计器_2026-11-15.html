一、今天要解决什么

给一段文本，统计每个字符出现了几次：

s = "abracadabra"
目标 → {'a': 5, 'b': 2, 'r': 2, 'c': 1, 'd': 1}

这件事看着新，其实是你 11-12 刚写的 avg[name] = average 换皮：那时候是「一个人 → 一个平均分」，今天是「一个字母 → 一个次数」。字典的所有用法都是同一个动作：按名字记一个数。

二、起手三问（先答，答案就是骨架）

问题今天的答案
结果存哪？count = {}（字典收集器，不是列表）
循环谁？for ch in s —— 对字符串 for = 逐字符遍历（第 4 周讲过，11-12 被 part[1] 咬过一次）
每轮干什么？这个字母见过 → 次数 +1；没见过 → 立户 =1

三、基础版：四行逻辑（先写这个）

s = "abracadabra"
count = {}

for ch in s:
    if ch in count:                 # 字典的 in 判 key —— 11-12 刚焊死
        count[ch] = count[ch] + 1   # 见过：+1
    else:
        count[ch] = 1               # 没见过：立户

print(count)

为什么必须有 else？ 因为 count[ch] = count[ch] + 1 的右边要先读 count[ch]——第一次遇到 a 时字典里根本没这把钥匙，读都读不到，直接 KeyError。else 就是替它把户头开出来。

四、进阶版：一行搞定（今天的重点）

11-12 快问快答 Q3 栽在 get 上——今天它立刻派上用场：

for ch in s:
    count[ch] = count.get(ch, 0) + 1

从里往外读：count.get(ch, 0) → 「这个字母记过几次？没记过就当 0」→ + 1 → count[ch] = 存回去。「函数只算、= 才存」这句话在这儿又出现了：get 只负责把旧值算出来，真正写回字典的是等号。

对照记牢：count.get(ch, 0) 用圆括号（请方法干活）；count[ch] 用方括号（按钥匙取值/赋值）。11-12 Q3 的 stu.get["height","没填"] 就是把这两个弄反了，报 TypeError: ... object is not subscriptable。

顺带：count[ch] += 1 是 count[ch] = count[ch] + 1 的简写，你 B 卷补做时已经用过 total += i。

五、三个升级（逐个加，别一次全上）

升级 1 · 打擂台找出现最多的字母

11-12 练习 2 的套路原样搬过来：

best_ch, best_n = "", 0
for ch, n in count.items():      # items() 发卡片，两变量接一对
    if n > best_n:
        best_n = n
        best_ch = ch
print(f"出现最多：{best_ch}，{best_n} 次")

升级 2 · 集合看「出现过哪些」

print(set(s))          # {'a','b','r','c','d'} —— 去重、无序
print(len(set(s)))     # 5 —— 不同字母的个数

集合不能下标、不保顺序，它的本职就三样：去重、成员判断、交并集。你 11-8 手写的 if name not in failed 判重，就是在手工模拟它。

升级 3 · 按次数从高到低输出（选做）

for ch, n in sorted(count.items(), key=lambda x: x[1], reverse=True):
    print(f"{ch}: {n}")

lambda 现在只要求照抄、不要求理解，第 6 周函数课正式讲。它的意思是「排序时看每一对的第 2 项（次数）」。写不出就用基础版 + 手工看，一样对。

六、完整参考代码

s = "abracadabra"
count = {}

for ch in s:
    count[ch] = count.get(ch, 0) + 1

for ch, n in count.items():
    print(f"{ch}: {n}")

best_ch, best_n = "", 0
for ch, n in count.items():
    if n > best_n:
        best_n, best_ch = n, ch
print(f"出现最多：{best_ch}，{best_n} 次")
print(f"不同字母：{len(set(s))} 个 → {set(s)}")
展开看正确输出（先自己跑，再对） 
a: 5
b: 2
r: 2
c: 1
d: 1
出现最多：a，5 次
不同字母：5 个 → {'a', 'b', 'r', 'c', 'd'}

注意 count.items() 的打印顺序按首次出现排列（a→b→r→c→d），集合那行顺序随机，都正常。

七、四个必躲的坑（都是你踩过的）

坑症状挡法
count.get[ch, 0] 方括号TypeError: not subscriptableget 是方法 → 圆括号
忘写 else 又没用 getKeyError（第一次遇到新字母）二选一：四行版带 else，或一行版带 get
for ch in count 以为拿到次数拿到的是 key（字母）要值用 count.items() 或 count[ch]
打印循环缩进进 for输出越印越多「print 全体要数据先齐」→ 住循环外
