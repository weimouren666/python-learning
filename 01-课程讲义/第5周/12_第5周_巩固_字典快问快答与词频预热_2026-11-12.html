三、三个考点，逐个焊死

考点 1 · get 用圆括号，不用方括号（Q3）

stu["height"]              # ❌ KeyError：按 key 取值，没有这个钥匙就炸
stu.get("height", "没填")   # ✅ "没填"：调方法，圆括号里放参数
stu.get["height", "没填"]   # ❌ 你写的

你那行实跑报的是：

TypeError: 'builtin_function_or_method' object is not subscriptable

读一遍：stu.get 本身是「住在字典家里的方法」，[] 是「按钥匙取值」，方法不是柜子，不能被下标。而且 ["height", "没填"] 里的逗号会拼成一个元组当钥匙——就算对象是字典也取不到。

符号用途例子
[] 方括号按位置/钥匙取值stu["age"]、scores[0]
() 圆括号调用函数或方法，里面放参数stu.get("height","没填")、len(scores)、print(...)

一句话：要「拿东西」用方括号，要「请它干活」用圆括号。 get 是请字典干活的，所以是圆括号。

考点 2 · 字典的 in 只认钥匙，不认值（Q5）

"hobby" in stu           # True  —— hobby 是 key ✅
"乒乓球" in stu          # False —— 它躺在 value 里，in 不往下翻盒子
"乒乓球" in stu.values() # True  —— 想判值，得先 .values()
type("hobby" in stu)     # <class 'bool'>

记忆钩子：字典的 in 是点名册点名——只喊名字（key），不检查你书包里装了什么（value）。这和你第 8 题的 avg[name] = average 是同一个道理：字典的一切入口都是 key。

Q5 还漏答了「类型」。True/False 的类型叫 bool（布尔型）——所有比较（>、==、in）的结果都是它。这是 11-5 字符串快问快答 Q5 之后第二次问类型没答上来，列为固定考点：以后凡问「结果和类型」，答案一律写「True，bool」这种双件。

考点 3 · key 已存在 = 覆盖，绝不会新增（Q8）

avg = {"张伟": 85.33, "李娜": 71.0, "王强": 67.0}
avg["张伟"] = 90.0
print(avg)      # {'张伟': 90.0, '李娜': 71.0, '王强': 67.0}
print(len(avg)) # 3 —— 还是 3 对，没有第 4 对

你答「会覆盖第一对，或者出现新的一对」——这个「或者」说明规则还没定死。既然题目明说「第 4 轮 name 和第 1 轮相同」，那 key 就是已存在，结果唯一：覆盖旧值，字典仍然 3 对。只有 name 是个从没见过的新名字时，才会新增第 4 对。

情况d[key] = value 的行为
key 不存在新增一对，len +1
key 已存在覆盖旧值，len 不变

顺带 · 集合长什么样（Q7）

你答的三个值是对的，写法补一下：集合的字面量是花括号，而且无序——沙箱实跑输出是 {'c', 'b', 'a'}，顺序和你写的 a、b、c 不一样，这很正常。set(["a","b","a","c"]) 的天职就是去重，别指望它排队，也不能用下标取。

五、周日实战课预热：词频统计器

11-15（周日）10:00 实战项目，把字符串 + 字典 + 集合 + 循环全家桶串起来。核心就是你已经写过的 avg[name] = average 的亲兄弟：

s = "abracadabra"
count = {}
for ch in s:
    if ch in count:            # 见过：+1
        count[ch] = count[ch] + 1
    else:                      # 没见过：立户，=1
        count[ch] = 1
print(count)
# {'a': 5, 'b': 2, 'r': 2, 'c': 1, 'd': 1}

三个升级点，周日现场讲：

  1. 一行版：count[ch] = count.get(ch, 0) + 1——今天 Q3 的 get 立刻派上用场（取不到就给 0，再加 1）；
  2. 打擂台找最高频字母：把今天练习 2 的 best_name/best_score 原样搬过来；
  3. 集合看「出现过哪些」：set(s) → 去重后的字母集；len(set(s)) → 不同字母个数。
