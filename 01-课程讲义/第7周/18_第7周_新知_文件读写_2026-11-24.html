第三节 · open()：开门三件套

读写文件的第一步永远是 open()——把它想成开一扇门，门后是硬盘上的文件：

f = open("scores.txt", "r", encoding="utf-8")
#   └文件路径     └模式     └编码
零件【知识点】
"scores.txt"文件路径。和 .py 文件在同一文件夹 → 只写文件名；不在 → 写相对/绝对路径。本质是个字符串
"r" / "w" / "a"模式：r = 读（read）、w = 写（write，覆盖）、a = 追加（append）。默认就是 r
encoding="utf-8"字符→字节的翻译规则。Windows 默认 GBK，Mac/Linux 默认 UTF-8——不写 encoding，中文容易变乱码。以后永远带上，肌肉记忆
⚠️ 坑①"w" 一开门就清空。对已有文件用 "w" 写入，旧内容瞬间蒸发，覆盖不商量。想保留旧内容追加，用 "a"。
⚠️ 坑②文件不存在时 open(..., "r") 报 FileNotFoundError——先检查文件名拼没拼对、在不在同一目录。

第四节 · 读文件：三种姿势

【知识点】读法一：read() 一口吞
f = open("scores.txt", "r", encoding="utf-8")
content = f.read()          # 整个文件读成一个【大字符串】
print(content)
f.close()                   # 用完关门（后面有更好的写法）

【知识点】读法二：逐行读（最常用！）
f = open("scores.txt", "r", encoding="utf-8")
for line in f:              # 文件对象天生可迭代，一次吐一行
    print(line.strip())     # strip() 掐掉行尾的换行符 \n
f.close()
【知识点】\n 是什么文件里每一行结尾都有一个看不见的字符 \n（换行符）。读出来的每行都带着它："张伟,88\n"。strip() 把两头的空白（含 \n）掐掉。不带 strip 直接 int(line) 就会炸 ValueError——这是今天第一大坑。

【联动】strip() 是第 4 周字符串方法，今天终于见到它的本职工作。for line in f 和你写过的 for w in text.split() 是同一家族：可迭代对象 → for 逐个处理，只是"逐个"的单位从"单词"变成了"行"。

第五节 · 写文件：w 覆盖、a 追加

【知识点】w 模式：覆盖写
f = open("result.txt", "w", encoding="utf-8")
f.write("第一行\n")          # write() 不会自动换行！\n 要自己写
f.write("第二行\n")
f.close()

【知识点】a 模式：追加写（旧内容保留）
f = open("log.txt", "a", encoding="utf-8")
f.write("又来一条记录\n")
f.close()
⚠️ 坑③write() 参数只能是字符串。f.write(88) 炸 TypeError，要写 f.write(str(88))——和 print 不一样，print 会自动帮你转。
⚠️ 坑④写完不 close()，内容可能还堵在缓冲区没落到硬盘上。所以——下一节的 with 才是正解。

第六节 · with 语句：自动关门

【知识点】with = 开门→办事→自动关门，一气呵成
with open("scores.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())
# 缩进结束后 f 自动关闭，不用手写 close()

为什么必须用它：文件是"系统资源"，开门要占系统的名额。忘了关门 → 文件被锁、数据丢失。with 把"关门"焊死在语法里，以后读写文件 100% 用 with，不用裸 open。

【知识点】as f和 for w in text 里的 w 一个道理：给开门拿到的"文件对象"起个变量名叫 f。文件对象支持：逐行 for、f.read()、f.readlines()（全部行装成列表）。

第七节 · 串联全课：读 CSV 成绩文件 → 函数统计

假设 scores.txt 内容（三行，CSV 格式，第 4 周你处理过一模一样的逻辑）：

张伟,88,92,76
李娜,92,95,88
王强,76,84,90

现在用文件 + 你第 6 周的函数，把整条流水线跑通：

def average(scores, digits=2):
    return round(sum(scores) / len(scores), digits)

def parse_line(line):
    【知识点】一行文本 → (名字, 分数列表)
    parts = line.strip().split(",")     # 先掐\n再切：顺序不能反
    name = parts[0]
    scores = [int(x) for x in parts[1:]]   # 列表推导式，第3周学的
    return name, scores

【知识点】主程序只负责"读文件、喊机器、打印"
with open("scores.txt", "r", encoding="utf-8") as f:
    for line in f:                      # 逐行：单位是"行"
        name, scores = parse_line(line) # 多返回值解包，第6周学的
        print(f"{name} 平均分：{average(scores)}")

看这条流水线的家族 resemblance：词频统计器是"逐字符/逐词处理字符串"，今天是"逐行处理文件"——for 循环 + 处理 + 收集的骨架从来没变过，变的只是数据从哪来。
