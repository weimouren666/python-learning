第一节 · wf.py 批改：✅ 通过，三台机器都转起来了

text = "python is great and data is great and python is fun"   ← 原料放全局

def count_words(text):          ← 机器一：def 造机器，参数 text 是投料口【知识点：def/参数】
    count = {}                  【知识点：空字典】跑 1 次，循环外
    for w in text.split():      【知识点：split() 无参=按空白切】切 11 个词，N 次
        count[w] = count.get(w,0) + 1   【知识点：get 默认值吞掉 if/else】
    return count                【知识点：return 递成品，没接=白算】

def most_frequent(count):       ← 机器二：打擂台【知识点：打擂台三步定式】
    best_w, best_n = "",0       立擂主——循环外，1 次【你 11-15 说反过、11-17 复述对了】
    for w, n in count.items():  【知识点：items 解包】逐个挑战，N 次
        if n > best_n:
            best_w, best_n = w, n
    return best_w, best_n       【知识点：多返回值=打包成元组】宣布结果，1 次

def distinct(word):             ← 机器三：⚠️ 这里埋着今晚的炸弹，第二节拆
    return len(set(words))      【知识点：set 去重 + len 计数】

words = text.split()
count = count_words(text)       【知识点：= 接住返回值——你练习 C 撞过 None 坑】
word, n = most_frequent(count)  【知识点：元组解包，两个盒子接两个值】
print("词频：", count)
print(f"出现最多：{word}，{n} 次")        【知识点：f-string 填变量】
print(f"不同单词：{distinct(words)} 个")

实测输出（与勘误后的预期一字不差）：

词频： {'python': 2, 'is': 3, 'great': 2, 'and': 2, 'data': 1, 'fun': 1}
出现最多：is，3 次
不同单词：6 个
三台机器、def 四件套、get、items 解包、多返回值解包、set——全对。两天的债一次还清。

第二节 · 代码侦查①：你代码里的隐形炸弹

再看一眼你的机器三：def distinct(word): —— 投料口叫 word，可机器内部用的却是 words（带 s）！参数根本没用上。

为什么还能跑出正确的 6？因为 words 在主程序里定义过，Python 在函数内部找不到 words，就跑到函数外面找到了全局的它。我做个实验证明它有多危险：

def distinct(word):
    return len(set(words))   # 用的是外面的全局 words，不是参数 word

words = [1,2,3]
print(distinct("随便传什么都行"))   → 3（跟传进去的东西毫无关系！）
结论：这程序是"歪打正着"——全局恰好有个对的 words 才没炸。换一个没有 words 的程序，直接 NameError。正确写法：函数体内只用参数 return len(set(word))。这暴露的知识点叫作用域，下一节正式讲。

第三节 · 函数（二）之一：作用域——Python 怎么找变量

知识点：作用域 作用域 = 一个变量名有效的范围。Python 找一个名字时按固定顺序：

顺序范围例子
1局部（函数内部）函数里定义的 count、best_w、参数 text
2全局（整个文件）顶格写的 text、words
3再找不到 → NameError哪里都没定义过
x = 10            # 全局 x

def f(x):         # 局部 x（参数也是局部变量！）
    x = x + 1     # 改的是局部那份，全局的 10 一动不动
    return x

print(f(x))       → 11
print(x)          → 10（全局没被改）
三条铁律：①参数和函数体内定义的都是局部，函数一结束就销毁；②函数内找不到才出门找全局；③函数内部改局部变量，永远不影响外面的同名变量。你的 distinct 就是违反了"该用局部却用全局"——现在你知道那发子弹为什么没响。

第四节 · 函数（二）之二：多返回值——你已经在用了

知识点：多返回值/元组打包解包 return best_w, best_n 其实是把两个值打包成一个元组递出来，外面 word, n = ... 再拆包。三步理解：

return best_w, best_n     # 等价于 return (best_w, best_n) —— 打包成元组
word, n = most_frequent(count)   # 元组解包：左边盒子数量 = 元组元素个数
# 也可以整个接住：
pair = most_frequent(count)      # pair = ('is', 3)，一个盒子装整个元组
数量必须对齐：a, b = (1, 2, 3) → ValueError: too many values to unpack。第 3 周学的元组，今天正式派上用场。

第五节 · 函数（二）之三：可变默认参数的世纪大坑

知识点：可变默认参数 默认值只在造机器时算一次，不是每次调用都重新造：

def add(x, box=[]):        # 坑！默认的 box 只造一次，每次调用共用同一个
    box.append(x)
    return box

print(add(1))    → [1]
print(add(2))    → [1, 2]   ← 不是 [2]！上次的 1 还躺在里面
print(add(3))    → [1, 2, 3]
原因：默认值 [] 在 def 那一刻创建一次，之后所有调用共享这个列表（可变对象会累积）。正确写法：默认值用 None，函数体内再新建：
def add(x, box=None):
    if box is None:      #【知识点：None——你练习 C 的老朋友】
        box = []
    box.append(x)
    return box

第六节 · 递归入门：函数喊自己

知识点：递归 函数在自己的内部调用自己。核心是两件事：递归出口（什么时候停）+ 递归公式（大问题怎么拆成小问题）：

def factorial(n):
    if n == 1:               # 出口：1! = 1，不再喊自己
        return 1
    return n * factorial(n-1) # 公式：n! = n × (n-1)!

print(factorial(5))    → 120
# 脑内展开：5! = 5×4! = 5×4×3! = 5×4×3×2! = 5×4×3×2×1! = 5×4×3×2×1 = 120
没出口 = 无限喊自己 → RecursionError: maximum recursion depth exceeded。今天理解即可，不死磕。递归的"调用栈"下周有空再用图画给你。
