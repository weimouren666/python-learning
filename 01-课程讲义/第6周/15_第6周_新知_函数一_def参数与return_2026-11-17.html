一、为什么需要函数（从你自己的痛点说起）

11-8 阶段测验后你说过一句很关键的话：「自己写小程序老是不知道怎么起手」。再看 11-10 的 shizhan4：每个人都要算一次平均分，那段 sum(part[1:])/len(...) 你写了三遍；词频统计器想换一段文字，得把整段复制一份。

三件事其实是同一个问题：同一段逻辑被重复写、且没有名字。函数就是给一段逻辑起个名字、装进盒子，以后要用只喊名字：

def average(scores):          # 给「算平均分」这件事起名叫 average
    return round(sum(scores) / len(scores), 2)

avg1 = average([88, 92, 76])  # 张伟
avg2 = average([92, 95, 88])  # 李娜 —— 同一台机器，投不同原料
一句话：函数 = 一台机器。投原料（参数）→ 内部加工（函数体）→ 吐成品（return）。以后看到 df.head()、value_counts() 全是这个东西，pandas 就是一堆现成的机器。

二、第一个函数：def 四件套

def greet(name):                    # ① def 名字(参数):  ← 冒号别丢
    message = "你好，" + name       # ② 函数体必须缩进 4 格
    return message                  # ③ return 把结果递出来

result = greet("魏常泽")            # ④ 调用：名字(原料)，用变量接住
print(result)                       # 你好，魏常泽
部件作用漏了会怎样
def 名(参数):登记这台机器 / 写说明书冒号丢了 → SyntaxError（你 11-3 被全角 ） 咬过，同类）
缩进的函数体机器内部的加工步骤不缩进 = 不属于这台机器 → IndentationError
return把成品递出机器不写 = 递出 None；写成 print = 只贴屏幕、递不出来
调用 名(原料)按启动键，机器才真的转只 def 不调用 → 什么都不会发生（最常见的新人错觉）
定义 ≠ 执行：def 那几行只是「把机器造好摆着」，Python 读过去不会跑函数体。只有写出 greet("魏常泽") 这一行，机器才转一次。这和「循环体=剧本，每轮重演」是同一套心智：写下来的只是说明书，喊名字才开演。

三、return vs print：回收「函数只算、= 才存」

这句话你 10-09 栽在 float(high)、11-01 又栽在 sorted(scores) 没接返回值 —— 今天它终于有了正式名字：return 就是「函数把算好的东西递出来」，调用处必须用 = 接住，否则白算。

def average(scores):
    return round(sum(scores) / len(scores), 2)

average([88, 92, 76])          # ① 算了，没接住 → 屏幕上什么都没有
print(average([88, 92, 76]))   # ② 直接把递出来的东西交给 print → 85.33
avg = average([88, 92, 76])    # ③ 接进盒子（推荐）→ 后面还能接着用
print("平均分：", avg)          # 平均分： 85.33
把 print 当 return 用是第二常见的坑： 
def average(scores):
    print(round(sum(scores) / len(scores), 2))   # 只贴屏幕，没递出来
avg = average([88, 92, 76])   # 屏幕显示 85.33，但 avg 是 None
print(avg + 1)                # TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'
判断标准：结果后面还要用 → return；只想让人看一眼 → print。

顺序也记一下：return 一执行，函数当场结束，后面的行不再跑。所以它通常放函数体最后。

四、参数三种写法（回收 11-5 那个坑）

def greet(name, punctuation="！"):      # punctuation 有默认值 = 默认参数
    return "你好，" + name + punctuation

greet("魏常泽")                        # 位置参数 → 你好，魏常泽！
greet("魏常泽", "？")                  # 两个位置参数 → 你好，魏常泽？
greet(name="魏常泽", punctuation="？")  # 关键字参数 → 你好，魏常泽？
greet(punctuation="？", name="魏常泽")  # 贴了标签就能换顺序 → 同上
写法长相规矩
位置参数greet("魏常泽")按位置对号入座，顺序错了就串味
关键字参数greet(name="魏常泽")给参数贴标签，可以换顺序；必须排在位置参数后面
默认参数def greet(name, p="！")不传就用默认值；有默认值的参数必须写在最后，否则 SyntaxError
11-5 那个报错，今天正式结案：你写过 print(s = "H" + s[1:]) → TypeError: 's' is an invalid keyword argument for print()。因为括号里的 name=value 是「给参数贴标签」，不是「给变量赋值」；print 没有一个叫 s 的参数，所以不认这个标签。
而 print("a", end="") 里的 end= 合法，是因为 print 真有这个参数（第 2 周讲 end 时你已经用过）。赋值永远独占一行：s = "H" + s[1:]，然后 print(s)。

顺带认亲：count.get(ch, 0) 的第二个参数、round(x, 2) 的 2、sorted(..., reverse=True) 的 reverse= —— 全是同一家参数，以前只管照抄，现在知道它们叫什么了。

五、lambda 正式讲（兑现 11-15 的「照抄」欠账）

11-15 升级 3 你照抄过 key=lambda x: x[1]，当时约定「第 6 周函数课正式讲」。它其实就是一台没名字、只有一行的小机器：

# 普通写法：先造机器，再把机器交给 sorted
def take_second(x):
    return x[1]

sorted(count.items(), key=take_second, reverse=True)

# lambda 写法：懒得起名，就地写一台一次性的
sorted(count.items(), key=lambda x: x[1], reverse=True)

语法 lambda 参数: 返回什么 —— 冒号左边是投进去的原料，右边是吐出来的成品，连 return 都省了（右边表达式的值自动就是返回值）。实测两种写法输出完全一致：[('a', 5), ('b', 2), ('r', 2), ('c', 1), ('d', 1)]。

为什么 key= 后面能接一台机器？因为 sorted 排序时要问「按什么排」，它把每一对 ('a', 5) 喂给 key 那台机器，机器吐出 5，就按吐出来的数排。这是「函数也能当原料传给另一个函数」，今天只要求看懂，不要求自己写。

现在的要求：能指着 key=lambda x: x[1] 说出「投一对、取第 2 项当排序依据」= 达标。自己发明 lambda 是第 8 周之后的事。

六、本讲完整参考代码

def average(scores):
    """返回平均分，保留两位。"""          # 文档字符串：给机器贴说明书，周四细讲
    return round(sum(scores) / len(scores), 2)

def greet(name, punctuation="！"):
    return "你好，" + name + punctuation

def most_frequent(count):
    best_ch, best_n = "", 0               # 擂主归零：1 次 → 循环外（11-15 刚焊死）
    for ch, n in count.items():
        if n > best_n:                    # 逐个挑战：N 次 → 循环内
            best_ch, best_n = ch, n
    return best_ch, best_n                # 多返回值：逗号一隔，外面两变量接（周四细讲）

scores = [88, 92, 76]
avg = average(scores)
print("平均分：", avg)                    # 85.33
print(greet("魏常泽"))                    # 你好，魏常泽！

count = {'a': 5, 'b': 2, 'r': 2, 'c': 1, 'd': 1}
ch, n = most_frequent(count)
print(f"出现最多：{ch}，{n} 次")           # 出现最多：a，5 次
