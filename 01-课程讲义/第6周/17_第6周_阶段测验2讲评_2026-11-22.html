第一节 · 第 1 题深挖：知识点：赋值使变量变局部

你以为：collect(5) 输出 5、再输出 10、最后 print(total) 报"未定义"。实际第一行 print 就炸了，后面两行根本没执行到。Python 的规矩是：

函数体内只要出现 total = ...（给它赋值），total 就被宣布为局部变量——哪怕全局有个 total 也不看。于是执行 total = total + n 时，右边的 total 是"还没赋值的局部变量"→ 读一个不存在的东西 → UnboundLocalError: cannot access local variable 'total' where it is not associated with a value。

执行流程逐行走：

total = 0                    # 全局 total = 0
def collect(n):              # 造机器（不执行）
    total = total + n        # ① Python 看到"函数内有 total=..." → 宣布 total 是局部的
                             # ② 执行时先算右边：读局部 total → 它还没被赋过值 → 炸
    return total
print(collect(5))            # UnboundLocalError ← 死在这里
print(collect(5))            # （没执行到）
print(total)                 # （没执行到。如果执行了，会输出 0，不是报错）
跟你的 distinct 炸弹对照：那是"该用参数却用了全局"（歪打正着能跑），这题是"想用全局却因为赋值变成了局部"（必炸）。两个方向合起来才是作用域全图：读：函数内没有才出门找全局；写：函数内赋值 = 造一个新的局部变量，和全局同名也无关。想让函数改全局 total？以后会学 global 关键字，但现在最好的做法是用参数传进去、用 return 拿出来——这正是函数存在的意义。

第二节 · 第 4 题深挖：in 的本质（第三次错，必须焊死）

你答 "age" in stu → 18。你把 in 当成了"把 age 的值拿出来"。in 是疑问句，不是取值动作：

写法读法返回
"age" in stu"字典里有没有叫 age 的钥匙？"——只回答有/没有True，类型 bool
stu["age"]"拿 age 这把钥匙对应的值"18
stu.get("age")同上，但钥匙不存在不炸，返回默认值18 / 默认值

知识点：in 判 key 记住：in 只认钥匙（key），不碰保险柜里的东西（value）。所以 "男" in stu 是 False——"男"是 value，不是 key。这题 11-12 答过 False（实为 True），11-22 答成 18——两次方向相反的错，说明不是笔误，是 in 的语义从来没立起来。一句话钉死：in 返回的永远是 True/False，回答"有没有"，回答不了"是多少"。

第四行 stu["gender"]：KeyError: 'gender'——方括号取值，钥匙不存在直接炸（get 才有"不存在给默认值"的温柔）。追加问的 len(stu) 答对了：key 不存在时赋值 = 新增，2 个变 3 个。

第三节 · 第 5 题深挖：{} 的第三次错案

type({}) 你答"空集合"。这是讲过两遍（11-15 词频课、讲义 14）的知识：{} 是空字典，空集合必须写 set()。历史永远偏向字典——因为 Python 设计时字典（花括号+冒号）先出现，集合只能用 set()。三条对照：

写法是什么
{}空字典（dict）
{1, 2, 3}集合（花括号里塞散值）
{"a": 1}字典（花括号里有冒号）
set()空集合（唯一正确写法）

set(nums)[0] → TypeError: 'set' object is not subscriptable——set 无序，没有"第 0 个"，四条规矩里的老规矩。

第四节 · 第 7 题深挖：你说对了位置，却推不出输出

位置（循环外）、理由（每轮被替换成 0）都说对了——但输出你答 92，实际是 76。逐轮推演：

轮1: s=88 → best=0（归零）→ 88>0 ✓ → best=88
轮2: s=92 → best=0（又归零！）→ 92>0 ✓ → best=92
轮3: s=76 → best=0（再归零！）→ 76>0 ✓ → best=76
return best → 76   # 只记得最后上台的，跟 11-15 的 d,1 一模一样

这就是 11-15 词频课你亲手撞过的反例（擂主放循环内 → 出现最多：d，1 次）——同一个病换了件衣服你就没认出来。所以读代码题的训练点：**别背结论，学会逐轮推演**——拿张纸写"轮1/轮2/轮3 变量怎么变"，推完答案自动出来。这也是 AI 时代读程序的核心功夫。

第五节 · 第 8 题深挖：可变默认参数

你答 (1)、(1,2)——值的方向对了但写成圆括号（那是元组），实际是列表 [1]、[1, 2]。你说不理解，讲透它只需一句话：默认值 [] 只在 def 造机器那一刻创建一次，之后每次调用用的都是同一个列表：

def add(x, box=[]):     # 造机器时创建了一个列表，假设给它起名叫 box_0 号
    box.append(x)
    return box
add(1)   # 往 box_0 号里放 1 → [1]
add(2)   # 还是往 box_0 号里放 2 → [1, 2]（不是新列表！）

数字默认值（digits=2）没事，因为数字不可变、没法"攒"；列表 dict 这类可变默认值才会攒出事故。安全写法：默认值用 None 哨兵。

第六节 · 第 6 题补讲：手写 average（你没做出来的那台机器）

def average(scores, digits=2):                       【def 四件套 + 默认参数】
    return round(sum(scores) / len(scores), digits)  【return 递成品；round 第二个参数就是位数】

print(average([88, 92, 76]))      → 85.33（digits 用默认值 2）
print(average([88, 92, 76], 1))   → 85.3（位置参数把 digits 覆盖成 1）

起手三问：结果是什么（平均分数字）→ 加工用什么（sum/len/round）→ 递出去（return）。你 11-17 练习 A 已经写过 average(scores)，这题只是多了个默认参数 digits——把 2 换成 digits 而已。卡住你的不是新知识，是"从零组装"。作业里再练一次。
