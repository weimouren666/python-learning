一、快问快答（先自己答，再点开对答案）

已知 scores = [88, 92, 76, 59, 100]，口头回答，别敲代码：

  1. scores[2] 是多少？
  2. 怎么取最后一个元素？
  3. scores[1:3] 是哪几个？
  4. 往末尾加一个 95，怎么写？
  5. 想知道列表里有几个元素，用什么？
  6. 想从高到低排序、又不想改原列表，怎么写？
  7. 元组和列表最核心的区别是什么？
  8. 85 in scores 返回的结果是什么类型？
👉 点开对答案
  1. 76（下标 2 = 第 3 个元素，下标从 0 开始）
  2. scores[-1]（负索引，-1 = 最后一个）
  3. [92, 76]（含头不含尾：下标 1、2，不含 3）
  4. scores.append(95) —— 千万别写 scores = scores.append(95)，append 返回 None，列表会没
  5. len(scores) → 5
  6. sorted(scores, reverse=True)（返回新列表，原件不动）
  7. 元组不可变（创建后不能增删改），列表可变；元组用圆括号
  8. bool（True / False，可以直接配 if 用）

全对 → 基础过关，直接进入深化；错 1-2 个 → 回顾 lessons/04 对应小节再继续。

二、深化 1：enumerate —— 编号和值，一把抓

上次的问题：想知道"第几个元素是什么"，要写 range(len(scores))，还得小心 i+1：

for i in range(len(scores)):
    print(f"第{i+1}个同学：{scores[i]}分")   # 编号从0，人称从1，容易晕

升级版：enumerate 每次直接给你一对「编号, 值」：

for i, s in enumerate(scores, start=1):
    print(f"第{i}个同学：{s}分")

三个要点：

  1. enumerate(scores) 会在遍历时自动数数，每次交给你「编号 + 元素」一对；
  2. for i, s in ... 用两个变量同时接 —— 这叫解包，先会照着用，第 6 周讲函数多返回值时你还会见到它；
  3. start=1 让编号直接从 1 开始，不用再 i+1，少一个出错点。
怎么选：只要值 → for s in scores；要编号+值 → enumerate。range(len()) 能用但啰嗦，见到要认识，自己写优先 enumerate。

三、深化 2：列表推导式 —— 一行生成一个列表

老需求：把每个成绩都 +5。你已经会的写法：

new = []
for s in scores:
    new.append(s + 5)
print(new)    # [93, 97, 81, 64, 105]

推导式：同样的意思，一行：

new = [s + 5 for s in scores]

读法（从左往右翻译）："对 scores 里的每个 s，生成 s + 5，收集成新列表"。方括号说明结果是列表，for 前面是"每个元素变成什么"，for 后面是"从哪遍历"。

再多看两个：

[s * 2 for s in scores]              # 每个翻倍
[len(name) for name in names]         # 每个名字的长度

还能带条件（只要部分元素）：

[s for s in scores if s >= 60]        # 只收及格的：[88, 92, 76, 100]
定位与要求：现阶段只要求能看懂、敢抄（讲义和参考代码里出现时不慌），自己从零写留到第 7 周后再要求熟练。它本质就是把"建空列表 + for + append"三行压成一行 —— 循环基本功不牢时，老老实实写三行版，一样对。

四、课堂练习（全部新题）

练习 1：颁奖名单（enumerate 组合拳）

已知 scores = [88, 92, 76, 59, 100]，输出（从高到低、带名次）：

第1名：100分
第2名：92分
第3名：88分
第4名：76分
第5名：59分
👉 点开看参考答案 
scores = [88, 92, 76, 59, 100]
ranked = sorted(scores, reverse=True)     # 先从高到低
for i, s in enumerate(ranked, start=1):   # 再发编号
    print(f"第{i}名：{s}分")

解析：先排序、再编号，两步各司其职。容易错点：直接对原列表 enumerate（没排序）；或者忘了 start=1 又不 i+1，名次从 0 开始。

练习 2：推导式三连

用列表推导式各写一行：

  1. 生成每个成绩减 10 分的新列表
  2. 生成所有不及格（<60）成绩的新列表
  3. 选做：生成标签列表 ['及格', '及格', '及格', '不及格', '及格']
👉 点开看参考答案 
[s - 10 for s in scores]                  # 1
[s for s in scores if s < 60]             # 2 → [59]
["及格" if s >= 60 else "不及格" for s in scores]   # 3 选做

解析：第 3 题"if...else"写在 for 前面（每个元素变成什么），而第 2 题的"if 过滤"写在 for 后面（筛选哪些进列表）—— 位置不同、职责不同，这是推导式最容易混的地方，现在见过即可，不要求记住。
