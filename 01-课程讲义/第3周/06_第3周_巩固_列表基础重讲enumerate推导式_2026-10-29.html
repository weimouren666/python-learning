一、重讲 1：下标不是"第几个"，是"偏移量"

Python 里列表的下标回答的问题不是"这是第几个"，而是"它离开头偏移了几格"。第一个元素偏移 0 格，所以是 [0]。

值88927659100
下标（离开头几格）01234
负下标（离开尾几格）-5-4-3-2-1
人称（第几个）第1第2第3第4第5

两条铁律：

  • 合法下标范围是 0 ~ len-1，出界就 IndexError: list index out of range；
  • 取"最后一个"永远第一反应 scores[-1]，不要写 scores[len(scores)]。

二、重讲 2：切片 = range 的孪生兄弟（含头不含尾）

scores = [88, 92, 76, 59, 100]
scores[1:3]   # [92, 76]     下标 1、2，不含 3 —— 和 range(1,3) 一个规矩
scores[:2]    # [88, 92]     省头 = 从头开始
scores[2:]    # [76, 59, 100] 省尾 = 到最后

口诀：左闭右开，取到终点前一个。要"第 2 到第 4 个"（人称），就写 scores[1:4]。

四、新知 1：enumerate —— 编号和值一把抓

for i, s in enumerate(scores, start=1):
    print(f"第{i}个同学：{s}分")
  • for i, s in ... 用两个变量同时接一对值，这叫解包；
  • start=1 让编号从 1 开始，不用再 i+1；
  • 怎么选：只要值 → for s in scores；要编号+值 → enumerate。

五、新知 2：列表推导式 —— 一行生成一个列表

new = [s + 5 for s in scores]        # 每个成绩 +5，收集成新列表
[s for s in scores if s >= 60]       # 只收及格的：[88, 92, 76, 100]

读法："对 scores 里的每个 s，生成 s+5，收集成新列表"。

定位：现阶段只要求能看懂、敢抄；自己从零写等到第 7 周后再要求熟练。基本功不牢时老老实实写三行版（空列表 + for + append），一样对。
