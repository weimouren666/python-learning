一、为什么需要列表

痛点：一个班 40 个学生的成绩，用现在的知识怎么存？

s1 = 88
s2 = 92
s3 = 76
……写到第 40 个，你想死

更致命的是：没法批量处理。想求平均分，你得写 40 遍加法；想排序，无从下手。

打个比方：变量是散落一地的东西，列表是一行带编号的储物柜——一个名字（列表名），一整排格子（元素），每格有编号（下标）。想拿第 3 格的东西，报编号就行。

它是什么：列表（list）是 Python 最常用的容器，用一个变量名存下任意多个值，值之间用逗号隔开，整体用方括号 [] 包起来。

scores = [88, 92, 76, 59, 100]   # 一个列表，5 个成绩
names = ["魏常泽", "张三", "李四"]  # 字符串也能存
mixed = [1, "abc", 3.5, True]        # 什么都能存（但不建议混用）

二、索引：从 0 开始，不是从 1

索引从 0 开始是新人踩坑率 No.1 的设计。记住这个类比：下标 = 偏移量。第 1 个元素距离列表开头 0 格，所以它的下标是 0。

写法含义例子（scores = [88, 92, 76, 59, 100]）
scores[0]第 1 个元素88
scores[2]第 3 个元素76
scores[-1]最后一个元素100
scores[-2]倒数第二个59
len(scores)元素个数5

切片（取一段）：scores[1:3] 取下标 1 到 3 之间 —— 含头不含尾，跟 range 同一个设计哲学，你早就认识它了。

scores[1:3]      # [92, 76] —— 从下标1到下标3（不含3）
scores[:2]       # [88, 92] —— 开头到下标2（不含）
scores[2:]       # [76, 59, 100] —— 下标2到结尾
scores[::2]      # [88, 76, 100] —— 每隔一个取一个
scores[-1]       # 100 —— 最后一个
记忆钩子：range 含头不含尾 → 切片 含头不含尾 → 下周字符串切片还是这一套。Python 的"不含尾"哲学，一次学会，三处受益。

三、增删改查（一张表够用）

操作代码效果
查scores[0] / scores[-1] / 切片按编号取
改scores[3] = 6059 → 60，直接覆盖那一格
增（末尾）scores.append(95)95 加到列表最后
增（指定位置）scores.insert(1, 70)70 插到下标 1 处，后面的往后让
删（按位置）x = scores.pop(0)移除下标 0 的元素，并把它返回给你

scores = [88, 92, 76, 59, 100]
scores[3] = 60            # 改：59 不及格 → 60 及格
scores.append(95)         # 增：末尾加一个 95
scores.insert(1, 70)      # 增：70 插到下标 1
scores.pop(0)             # 删：移除第一个（88）
scores.remove(76)         # 删：移除值为 76 的那个
print(scores)              # [70, 92, 59, 100, 95]
坑：append 不返回新列表！scores = scores.append(95) 是经典错误 —— append 就地修改列表，返回 None，这样写会让 scores 变成 None。正确写法就是直接 scores.append(95)，别赋值。
坑：remove 删不存在的值会报错。scores.remove(999) → ValueError: list.remove(x): x not in list。删之前可以先 if 999 in scores: 判断一下（见第六节 in）。

四、遍历：两种姿势，各管各的场合

姿势 1：只要值，不要编号——逐个取出元素（九九乘法表的内层循环就是这么用 for 的，你早会了）：

for s in scores:
    print(s)

姿势 2：既要值又要编号——配合 range(len(scores)) 生成所有合法下标：

for i in range(len(scores)):
    print(f"第{i+1}个同学：{scores[i]}分")   # 注意 +1：编号从0，人称从1
怎么选：只处理每个元素 → 姿势 1；需要知道"这是第几个"（比如打印名次）→ 姿势 2。range(len(scores)) 这个组合以后每周都会出现，眼熟它。

五、常用函数与排序

函数作用例子
len(scores)个数5
sum(scores)总和415
max(scores)最大值100
min(scores)最小值59
sorted(scores)返回排好序的新列表，原列表不动[59, 60, 92, 95, 100]
sorted(scores, reverse=True)降序（从高到低）[100, 95, 92, 60, 59]

平均分一行搞定：sum(scores) / len(scores) —— 想保留两位小数？round(sum(scores)/len(scores), 2)，你的老朋友 round 又上场了。

坑：sorted(列表) vs 列表.sort()
· sorted(scores) 是函数，返回新列表，原列表不变；
· scores.sort() 是列表自带的方法，直接改原列表，不返回新列表。
入门阶段统一用 sorted()，不容易闯祸；两者的区别第 6 周讲函数时还会细说。

六、in：成员判断

85 in scores        # True/False —— 85 在不在名单里
"魏常泽" in names     # True —— 字符串列表照样好用
999 in scores       # False

in 就是逻辑判断里的"在不在"，返回 True/False，直接配 if 使用：if 85 in scores: print("有这号人")。上周学的 and/or/not 和它配合无间。

七、元组：不许变的列表

它是什么：元组（tuple）和列表几乎一样，但创建之后不能增删改。语法上用圆括号 ()：

point = (3, 5)              # 平面上的一个点：x=3, y=5
print(point[0], point[1])    # 3 5 —— 读取和列表一样
point[0] = 9               # TypeError! 元组不支持修改

打个比方：列表是白板，随写随擦；元组是刻在石头上的字。一个点的坐标、一次考试的级别、RGB 颜色值 (255, 0, 0) —— 这些"本来就不该被改"的数据，用元组更安全（防止手滑改错），程序也跑得稍微快一点。

列表 list元组 tuple
符号[]()
能否增删改能不能
典型用途一堆会变的数据（成绩、购物车）一组固定的数据（坐标、颜色、日期）
元组支持的操作就三样：读取（下标、切片、遍历）、len、in。记不住用哪个的时候，选列表 —— 90% 的场景列表都够用。

练习 1：切片预测（不动手，先想，再敲出来对答案）

已知 scores = [88, 92, 76, 59, 100]，心算下面每个式子的结果：

scores[1]        → ?
scores[-1]       → ?
scores[1:3]      → ?
scores[:2]       → ?
scores[3:]       → ?
len(scores)      → ?

👉 点开看参考答案 
scores[1]     → 92      （下标1是第2个）
scores[-1]    → 100     （最后一个）
scores[1:3]   → [92, 76]（含头不含尾：下标1、2）
scores[:2]    → [88, 92]（开头到下标2）
scores[3:]    → [59, 100]
len(scores)   → 5
max(scores)   → 100

解析：错哪个补哪个。下标从 0 和"不含尾"是本课两大坑，全对才算过关。

练习 2：不用 sum，用老办法算总分

用 for 循环 + 累加器（你算 5050 那招）把 scores 的总分算出来，再用 sum(scores) 对比，验证两个结果一样。

👉 点开看参考答案 
scores = [88, 92, 76, 59, 100]
total = 0                    # 累加器，初始 0
for s in scores:
    total = total + s        # 每个成绩往上加
print(total)               # 415
print(sum(scores))          # 415 —— 一模一样

解析：这个练习是让你看穿 sum() 的本质 —— 所谓标准库函数，就是前人替你写好的循环。你手写的 4 行代码，Python 一个词就等价。会手写，才敢用函数；敢用函数，才走得快。

九、常见坑汇总（本课专属）

坑 1：下标从 1 开始数 —— scores[1] 是第 2 个元素，不是第 1 个。下标 = 偏移量，第一个元素偏移 0 格。
坑 2：切片右边界当 inclusive —— scores[1:3] 只有下标 1、2 两个元素，不含 3。range 的老规矩。
坑 3：scores = scores.append(x) —— append 返回 None，这样写列表直接没了。增删改都是"打电话"式的就地操作，不要接返回值。
坑 4：sorted() 和 .sort() 分不清 —— 一个返回新列表不动原件，一个直接改原件不返回。入门先用 sorted()。
坑 5：越界访问 —— scores[10]（只有 5 个元素）→ IndexError: list index out of range。看到 IndexError 就知道：编号超范围了。用 len(scores) 先量一下长度最稳。
