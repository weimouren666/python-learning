一、字符串就是"字符的列表"

你学过的列表操作，字符串几乎全套通用——这是本课最大的省力消息：

s = "hello"
s[0]        # 'h'          下标从 0，和列表一模一样
s[-1]       # 'o'          负下标取尾
s[1:3]      # 'el'         切片，含头不含尾
len(s)      # 5
'h' in s    # True         成员判断
for ch in s: print(ch)    逐字符遍历

为什么通用？它们都是"序列"——一格一格排好队的东西。学会一个，两个都会。

二、字符串不可变（和元组一伙的）

s = "hello"
s[0] = "H"      # TypeError! 字符串不能原地改

所有字符串方法都是"返回新字符串，原件不动"——所以永远要接返回值：

s = "  wei changze  "
s = s.strip()       # 去掉两头的空格，必须 = 存回！
老坑新装：s.strip() 写了不存回 = 白做。"函数只算、= 才存"在字符串界比列表界更容易踩，因为方法名看起来像已经"改好了"。

三、六个高频方法（今天必须混个脸熟）

方法作用例子
s.strip()去掉两头的空格（含换行）" hi ".strip() → "hi"
s.upper() / s.lower()全大写 / 全小写"Abc".lower() → "abc"
s.replace(旧, 新)替换所有出现"aaa".replace("a","b") → "bbb"
s.split(分隔符)切开 → 得到列表！"a,b,c".split(",") → ['a','b','c']
s.find(子串)查位置，找不到返回 -1"hello".find("ll") → 2
s.count(子串)数出现次数"banana".count("a") → 3

split 是字符串和列表的握手：切完就是列表，你上周学的列表功夫全部接得上。

四、input + strip 的黄金搭档

name = input("请输入姓名: ").strip()      # 链式调用：input 完立刻去空格
age  = int(input("年龄: ").strip())       # 先去空格再转 int，防手滑多打空格

从今天起，写 input 建议习惯性带 .strip()。

五、f-string 深化：你已经会 80%，补最后一口

pi = 3.14159
print(f"π 约等于 {pi:.2f}")        # π 约等于 3.14   —— :.2f 保留两位小数
print(f"[{name:>10}]")             # 右对齐占 10 格（表格排版用）
print(f"[{name:<10}]")             # 左对齐
n = 1234567
print(f"{n:,}")                    # 1,234,567 —— 千分位
