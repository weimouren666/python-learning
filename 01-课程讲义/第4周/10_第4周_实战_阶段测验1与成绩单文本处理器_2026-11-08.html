二、起手三问（写小程序的万能起手式）

  1. 结果存哪？求和/计数 → 累加器 total = 0；收集一批 → 收集器 lst = []
  2. 循环谁？固定次数/等差 → for i in range(a, b, s)；遍历现成一堆 → for x in 列表；不知道几轮 → while True + break
  3. 每轮干什么？累加/收集/判断（if 在循环体内）

三、错题监控名单（下次测验重点）

  • range(a, b, s) = 从 a 数到 b 前一个，每次跳 s（口诀背死）
  • sorted(x) 返回新列表原列表不动；x.sort() 才改原件
  • end="" = 后面什么都不接（不是空格）

四、实战项目：成绩单文本处理器（shizhan4.py）

这是你手写的第一个"数据处理流水线"，也是 pandas 的原始形态。

数据

data = "张伟,88,92,76\n李娜,59,73,81\n王强,45,66,90"

注意 \n：这是一个字符——换行符。三行文本挤在一个字符串里，靠它分行。

需求

  1. 把 data 按换行符切开，得到每个学生一行的列表
  2. 遍历每一行：用今天的 CSV 套路（split → 切片取成绩 → int 转换收集）算出每个学生的平均分并输出（round 两位）
  3. 算全班总平均分（所有成绩一起算）
  4. 选做 ①：输出谁的平均分最高；选做 ②：列出有不及格科目的学生

起手三问提示

  • 外层循环谁？→ 按行切开后的列表
  • 每行干什么？→ 复用 CSV.py 的四步（split/切片/int/收集）
  • 全班总平均需要什么？→ 再造一个收集器，把所有人的成绩都收进来
