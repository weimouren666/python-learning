什么是 pandas？

石家庄学院 · 数据科学与大数据技术 · 大一入门讲义  |  2026年10月

一句话定义：pandas 是 Python 里专门用来处理表格数据的库 —— 相当于把 Excel 的能力装进了代码里，还顺便给了它处理百万行数据的体力和"一次写好、重复运行"的记忆。

一、它到底解决什么问题

1. 原生 Python 处理表格，其实是件痛苦的事

你现在还没学 Python，但可以想象：如果让你用最原始的方式存一张成绩表，你大概只能写成"列表套列表"：

data = [
    ["张三", "大数据", 88, 90, 78],
    ["李四", "大数据", 92, 85, 80],
    ["王五", "大数据", 75, 88, 92],
]

问题立刻来了：第 3 个数是什么？得靠脑子记"第 2 列是高数"。想筛出高数 90 分以上的，得写循环；想按专业分组求平均，又得写嵌套循环加字典；想算中位数、标准差……自己实现一遍。能写，但又啰嗦又容易错。

而 pandas 把这张表变成一个有列名、有行号、能整体运算的对象：

df[df["高数"] >= 90]              # 筛选：一行搞定
df.groupby("专业")["高数"].mean()  # 分组求平均：一行搞定
df.describe()                     # 全部统计量：一行搞定

2. 那为什么不直接用 Excel？

Excel 非常强，但它有三个硬伤，而这三个硬伤恰好是 pandas 的强项：

场景Excelpandas
数据量大几万行开始卡，十万行基本动不了百万行依然秒级响应
重复劳动每月都要手动点一遍，人肉操作代码写一次，以后一行命令重跑
可追溯"这个数怎么来的"说不清，容易出错还查不出每一步都有代码记录，可复现、可 review

再加一个你可能没意识到的点：Excel 的操作没法交给程序自动跑。比如老师让你分析 30 个文件，Excel 要点 30 遍，pandas 写个循环 3 秒搞定。

3. 名字从哪来的

不是熊猫。来自计量经济学术语 Panel Data（面板数据），缩写 pan-da-s。作者 Wes McKinney 2008 年在金融公司上班时写的，最初就是为了处理金融时间序列。（顺便：它的吉祥物确实是熊猫 🐼）

二、两个核心概念：Series 和 DataFrame

pandas 全部的东西，就建立在这两个数据结构上。搞懂这两个，pandas 就懂了一半。

Series —— 一列数据

带"标签"的一维数组。你可以理解为 Excel 里的一列，而且每一格除了值还有个名字（索引）。

0    88
1    92
2    75
3    61
Name: 高数, dtype: int64

左边 0 1 2 3 是索引（行号），右边是值，底下那个 高数 是这一列的名字。

DataFrame —— 一张完整的表

若干列 Series 拼起来，就是 DataFrame。它有行索引 index 和列名 columns 两个方向，像一张真正的二维表：

   姓名   专业  高数  Python    英语
0  张三  大数据  88      90  78.0
1  李四  大数据  92      85  80.0
2  王五  大数据  75      88  92.0
3  赵六   计科  61      72  75.0

关系一句话：DataFrame = 多个 Series 按列拼起来。取出其中一列（df["高数"]）就得到一个 Series。

五、它在你这个专业里的位置

你们专业叫"数据科学与大数据技术"，pandas 处在这条技术栈的正中间：

   NumPy          ← 底层：多维数组与数值计算（第 10 周）

     ↓

它跟其他课的关系

  • 数据库（SQL）：groupby 就是 SQL 的 GROUP BY，merge 就是 JOIN。学完 pandas 再学 SQL 会非常轻松，反之亦然。
  • 概率统计：describe() 输出的均值、标准差、四分位数，就是你课上学的那些概念的真实落地。
  • 线性代数：pandas 底下的 NumPy 数组，就是矩阵运算的载体。
  • 机器学习：sklearn 模型的输入，绝大多数时候就是一个 DataFrame。pandas 用得不熟，机器学习根本没法往下走。
  • 大数据框架（Hadoop/Spark，后面年级会学）：Spark DataFrame 的设计几乎是照着 pandas 抄的，概念高度相通。
就业视角：数据分析师、数据工程师、算法工程师、商业分析岗 —— 不管哪个方向，pandas 都是写在招聘要求第一条的基础技能。它是这个专业性价比最高的一项投资。

六、它的边界（别指望它啥都能干）

pandas 擅长pandas 不擅长
单机内存装得下的表格数据（百万行 ~ 千万行量级）TB 级超大数据（要用 Hadoop / Spark 分布式）
结构化数据：CSV、Excel、数据库表图片、音频、文本等非结构化数据
复杂的数据清洗、变形、聚合毫秒级实时流处理（那是 Flink 的活）
探索性分析、快速试想法高并发的生产服务

核心认知：pandas 是"单机内存工具"。数据能不能装进你的内存，是它能不能干活的分界线。这也正好解释了你们专业为什么还要学 Spark —— 那是"数据大到一台机器装不下"时的答案。

七、一段真实代码长什么样

下面这段是在本机真实跑出来的结果（6 名同学的成绩表）：

import pandas as pd

df = pd.DataFrame({
    "姓名": ["张三", "李四", "王五", "赵六", "钱七", "孙八"],
    "专业": ["大数据", "大数据", "大数据", "计科", "计科", "计科"],
    "高数": [88, 92, 75, 61, 95, 70],
    "Python": [90, 85, 88, 72, 91, 66],
    "英语": [78, 80, 92, 75, 88, None],   # 孙八缺考
})

# 一行代码，全部统计量
df.describe().round(1)
#        高数  Python    英语
# count  6.0     6.0     5.0     ← 英语只有5个，自动发现缺考
# mean  80.2    82.0    82.6
# std   13.6    10.4     7.1
# min   61.0    66.0    75.0
# 50%   81.5    86.5    80.0
# max   95.0    91.0    92.0

# 按专业分组求平均
df.groupby("专业")[["高数", "Python"]].mean()
#         高数  Python
# 大数据  85.0    87.7
# 计科    75.3    76.3

注意那个 count 5.0 —— pandas 自动识别出英语有 1 个缺失值，并且算平均时自动把它排除了。这种细节正是它值钱的地方：它替你记住了那些你容易忘的事。

八、现在该不该直接学 pandas？

我的建议：不要。至少先花 10 周把 Python 语法打扎实。

原因很实在，pandas 的很多写法依赖你对基础语法的直觉：

  • df[df["高数"] >= 90] —— 这其实是"字典取值"加"布尔判断"的组合，你不懂字典和布尔值就看不懂它凭什么能筛选；
  • df.apply(lambda x: ...) —— 要懂函数、匿名函数；
  • 索引和切片 —— 要懂 Python 的 [start:stop:step] 语法。

跳过基础直接上 pandas，会出现一种典型状态：能照着抄，但换个需求就完全写不出来，报错也看不懂。这是绝大多数初学者的坑。

所以我们的 14 周计划里，pandas 被放在第 11—12 周，前面用 10 周铺垫：变量 → 循环 → 列表（列的感觉） → 字典（索引的感觉） → 函数 → 文件读写 → 类 → NumPy。等你走到第 11 周会发现：pandas 的很多概念你已经"提前认识过"了，学起来是水到渠成而不是硬啃。

现在你唯一要做的：把 Anaconda 装好（里面自带 pandas），能跑出一句 print("Hello")。第 11 周我们会真正打开它。

九、一句话总结

pandas 不是一个"要背诵的库"，它是一种"用代码操作表格"的思维方式。它的 API 有几百个函数，没人记得全 —— 真正的能力是：拿到一堆脏数据，知道该先清洗什么、怎么分组、怎么验证结论。这个能力，才是你这个专业四年里真正要练的东西。pandas 只是你手里的那把刀。
