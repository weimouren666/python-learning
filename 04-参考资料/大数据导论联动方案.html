四、两个已验证的实验（现在就能跑）

实验 2：手写 K-Means（对应 4.4.1 节）

这个实验的价值在于：它只用到你第 6 周（函数）和第 10 周（NumPy）就能写出来，而且不依赖 sklearn。核心逻辑只有两步，循环往复：

# 1. 分配：每个点归到离它最近的簇心
labels = ((X[:, None, :] - centers[None, :, :])**2).sum(axis=2).argmin(axis=1)

# 2. 重算：每个簇心 = 该簇所有点的平均值
new_centers = np.array([X[labels == i].mean(axis=0) for i in range(k)])

# 3. 簇心不再移动 = 收敛
if np.allclose(new_centers, centers): break

真实运行结果（120 名学生的身高体重，聚成 3 类）：

簇心（身高cm, 体重kg）：
  簇1   身高 174.9   体重 54.8   ← 最接近：运动型
  簇2   身高 165.3   体重 49.8   ← 最接近：学术型
  簇3   身高 159.7   体重 79.5   ← 最接近：社交型

混淆矩阵（行=真实身份，列=算法分簇）：
             簇1   簇2   簇3
真实运动型:   34    6    0
真实学术型:   11   29    0
真实社交型:    1    0   39

聚类准确率 = 85.0%
我在写这个示例时踩了一个真实的坑，值得你注意：第一版数据我只跑到 52.5% 准确率，因为随机初始化让算法掉进了局部最优。修正方法是多次随机重启、取簇内平方和最小的那次 —— 这就是真实工程里的标准做法。算法也有运气成分，这个体感比背定义深刻得多。

六、怎么和教材配合着走

  1. 课上：正常听课，记下老师强调的概念和考点（这门课概念多、计算少，重点是体系框架）。
  2. 课后 1 周内：打开对应章节，配着上表的 Python 实验做一遍。拖久了就忘了，成本最高。
  3. 每章结束：把该章实验整理进你的 GitHub 仓库（按 `导论课/ch03_数据处理/` 这样组织）。
  4. 每章的「习题与实践」：概念题按教材答；实践题尽量用 Python 重做一遍。
  5. 期末前：12 章的实验合起来，就是你报告的素材库，从里面挑一个方向做深。
最后一句实话：这门课你完全可以"用 Python 打通"。概念你照教材理解，方法你用代码验证，报告你用真实数据做出来。到期末你会发现自己是班里少数几个**真的动手做过**的人 —— 而这正是这个专业最看重的区别。
