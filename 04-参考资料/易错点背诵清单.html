第 5 周 · 字典与集合（2026-11-09 起教）

#级别口诀为什么
11⭐⭐⭐in 是疑问句：只答"有没有"，永远 True/False（2026-11-24 ✅ 已焊死）"是多少"用 stu["age"] 或 stu.get("age")。in 只认 key，不认 value（"男" in stu 是 False——男是值不是钥匙）
12⭐⭐⭐{} 是空字典，set() 才是空集合（学生自报不牢固，下次抽查）花括号里有冒号 = 字典；塞散值 = 集合；空的偏向字典（历史原因）。type({}) → dict
13⭐⭐⭐只做 1 次住循环外，跑 N 次住循环内11-15 打擂台实战诞生口诀。归零/建表/收尾打印 = 1 次（外）；逐个判断/累加/存 = N 次（内）。擂主放循环内 → 每轮清空 → 只记得最后上台的（词频 d,1 / find_max 76 两次实证）
14⭐⭐字典 key 不存在 = 新增；已存在 = 覆盖stu["gender"]="男" 后 len 从 2 变 3。不存在+覆盖必是唯一结果，len 变或不变要能推
15⭐⭐方法用圆括号，取值用方括号stu.get("height", 0) ✓；stu.get["height"] → TypeError（方法不能下标）。[] 取值 key 不存在炸 KeyError，get 有默认值不炸
16⭐答案双件制：值 + 类型bool 已漏答两次后焊死。凡问"输出什么"，必须带 type
17⭐set 无序：不能下标、别信打印顺序set(x)[0] → TypeError。set 四条规矩：去重 / len 数个数 / 对字典只取 key / 不能下标

第 6 周 · 函数（2026-11-16 起教）

#级别口诀为什么
18⭐⭐⭐读代码要逐轮推演，不背结论拿纸写"轮1/轮2/轮3 变量怎么变"。测验 2 第 7 题：位置理由全对、输出推错 92（实为 76）——会说不会计的证据
19⭐⭐return 递成品，print 贴屏幕函数没 return，调用处接到 None；None + 1 炸 TypeError: NoneType + int（11-17 亲测）。结果还要用 → return；只想看 → print
20⭐⭐括号内 name=value 是贴标签，不是赋值print(s = "H"+s[1:]) 报 invalid keyword argument——print 没有叫 s 的参数。赋值永远独占一行；end="" 合法是因为 print 真有 end 参数
21⭐函数内赋值 → 变量变局部total = total + n 在函数内 = total 是局部的，读它炸 UnboundLocalError（哪怕全局有同名）。读：先局部后全局；写：函数内想改全局用参数传 + return 拿
22⭐可变默认参数会攒def f(x, box=[]) 的 [] 只在造机器时创建一次，每次调用共用 → [1] → [1,2]。数字默认值没事。安全：box=None + 函数体内 if box is None: box=[]
23⭐多返回值 = 打包元组递出，外面解包return a, b ↔ x, y = f()；左边盒子数 = 元组元素数，否则 ValueError。整个接住也行：pair = f()

方法论（不是知识点，是起手式）

场景起手式
写小程序不知怎么起手起手三问：①结果存哪 ②循环谁 ③每轮干啥
判断代码该缩进还是顶格1 次 vs N 次：这行要跑 1 次（外）还是 N 次（内）？
读代码逐轮推演：拿纸写每轮变量怎么变，不背结论
遇到报错三问：这个值是什么？从哪来？我想要什么？——先读 Traceback 最后一行类型名
设计函数机器三件：投原料（参数）→ 加工（函数体）→ 吐成品（return）
