① 编程基础 13 个

编程programming
把解决问题的思路翻译成计算机能执行的指令序列。写代码的本质是"把话说得足够精确"。
例："把成绩单里不及格的挑出来" → 人会说，你得写成精确的步骤。
程序program
一段能跑起来的代码。程序 = 数据 + 处理数据的指令。
代码code
指令的具体文本。写在文件里的代码叫"脚本"，能让它处理不同输入才是"程序"。
解释器interpreter
把你的代码一句句翻译成机器能执行的动作。Python 自带解释器，所以不需要先"编译"。
类比：翻译官。Java 需要编译器（一次翻译成 .class），Python 用解释器（边翻译边执行）。
变量variable
给一个值起个名字，之后用名字代替它。名字可以随便起，但要用有意义的英文名。
例：score = 88 之后写 print(score)，不用每次重新写 88。
数据类型data type
值的种类。Python 主要四种：int 整数、float 小数、str 文字、bool 真假（True/False）。
关键：计算机不区分"数字"和"文字"，5 和 "5" 对它来说是两个完全不同的东西。
类型转换type casting
在几种类型之间来回换。int("88")、str(88)、float("3.5")。
为什么重要：input() 拿到的永远是文字，所以"输入数字后做运算"必须先转换，否则会报错或算出怪结果。
运算符operator
做运算的符号。三个新手必混淆的：/ 真除法（5/2=2.5）、// 整除（5//2=2）、% 取余（5%2=1）。** 是幂（2**3=8）。
注释comment
写给人看的说明，Python 里用 # 开头，程序不执行它。
为什么重要：三个月后看自己的代码会完全看不懂。写注释是给自己未来写信。
缩进indentation
Python 用缩进（Tab 或 4 个空格）表示"这行属于上面那行"。这是它最鲜明的特点，也是最常见的报错来源。
注意：同一个代码块里缩进必须一致，用 Tab 和空格混用会报 IndentationError。
布尔值boolean
只有两个值：True 和 False，表示"是/否"。由比较运算产生：88 >= 90 → False。
真值判断truthiness
Python 里，空字符串、0、空列表都被当作 False，其余当 True。写判断时很好用。
例：if name: 意思是"如果名字不是空的"。
逻辑运算符and / or / not
把多个条件组合起来。and 全真才真，or 有一个真就真，not 取反。

② 容器类型 11 个 —— Python 的灵魂

列表list
一排有序、可修改的值，用方括号。[88, 92, 75]。
类比：一张可以随时涂改的清单。在 pandas 里，一列就是一条列表。
元组tuple
和列表几乎一样，但创建后不能修改，用小括号 (1, 2)。
用在哪：表示"一组不该被改动的值"，比如坐标、日期。多返回值也用元组返回。
字典dict
一堆"名字 → 值"的对应关系，用大括号。{"姓名": "张三", "高数": 88}。
类比：通讯录 —— 查名字得到电话。在 pandas 里，列名就是字典的键。JSON 数据格式本质就是字典 + 列表。
集合set
不重复、无顺序的一堆值，用 {}（空的时候要写 set()）。最大用途：去重和求交集/并集。
例：找出两篇文章的共同用词：set(词1) & set(词2)。
索引index
元素在容器里的位置编号，从 0 开始数。[88,92,75] 里 88 的索引是 0，92 是 1。
坑：长度为 3 的列表，最大索引是 2。写 lst[3] 会报 IndexError。
切片slicing
取出一段：lst[start:stop:step]，含头不含尾（stop 取不到）。lst[1:3] 取索引 1、2。
坑：lst[:2] 前两个，lst[2:] 从第 2 个到末尾，lst[::2] 每隔一个取一个。
可变 vs 不可变mutable / immutable
列表和字典能改，数字、文字、元组不能改。改不了的东西更安全，函数传参时尤其重要。
嵌套nesting
容器里装容器。{"班级": {"张三": [88, 90]}}。pandas 的行列结构本质就是二维嵌套。
遍历iterate / loop
把容器里的元素一个一个取出来处理。for x in 列表:
列表推导式list comprehension
用一行代码写出"循环 + 收集结果"，Python 的标志性写法。[x*2 for x in lst if x>60]
为什么重要：pandas 的很多筛选写法就是它变体，看着眼熟就容易懂。
NoneNone
表示"这里什么都没有"，和 0、空字符串不一样。None 是"没有值"，0 是"值就是零"。

③ 函数与工程 12 个

函数function
一段取名字、可反复调用的代码块。def 定义，调用时执行。
为什么重要：从"一堆顺序代码"到"能拆分成模块"，这是编程思维的分水岭。代码超过一屏就该拆函数。
参数parameter
调用函数时传进去的数据。位置参数按顺序对应，关键字参数按名字对应，默认参数可以不给。
可读性：能用关键字参数就别用位置参数 —— plot(x, label="高数") 比 plot(x, "高数") 强得多。
返回值return
函数"吐出来"的结果。return 之后的代码不执行。没有 return 的函数默认返回 None。
作用域scope
变量在哪一段代码里有效。函数内部定义的变量，出了函数就没了。
坑：函数里想改外面的全局变量要用 global 声明，但多数时候更好的做法是用参数传进去、用 return 带出来。
递归recursion
函数自己调用自己。必须有一个"终点条件"否则会无限循环。
类比：俄罗斯套娃 —— 每个套娃里有个更小的套娃，最后一个里面是空的。
模块module
一个 .py 文件。import 进来就能用别人写的函数。
包package
一堆模块的目录，用 from 包 import 模块 引入。pandas、numpy 都是包。
库 / 框架library / framework
别人写好的现成代码。库：你调用它（pandas、numpy）。框架：它规定好结构，你往里填代码（Web 框架）。
APIAPI
一个库对外开放的"按钮清单"。你不需要知道它内部怎么实现，只要知道"调哪个函数能得到什么"。
类比：餐厅菜单。菜单上写清"鱼香肉丝 38 元"，你不用进厨房。函数就是菜单上的菜名 + 参数。
第三方库3rd-party library
别人发布在网上、你用 pip install 装的库：pandas、numpy、matplotlib、requests。
虚拟环境virtual environment
一个项目独立的 Python 环境，让不同项目可以用不同版本的库而不打架。Anaconda 自带 conda 环境。
现在：知道有这个概念就行，实践中用 Anaconda 默认环境就够了。
文档字符串docstring
写在函数开头、三引号包起来的功能说明。help(函数) 或鼠标悬停就能看到。

④ 报错与调试 9 个

报错 / 异常exception
程序运行时出错。Python 会告诉你哪一行、什么类型的错误。
重要观念：报错不是坏事，是程序在跟你说话。学会读报错是核心能力。
Tracebacktraceback
报错时打印的那一长串信息，告诉你错误从哪来、经过哪几行、在哪一行炸了。
读法：先看最后一行（真正的错误原因），再看倒数第二行（出错的代码位置）。
SyntaxError语法错误
代码本身写法不对，Python 还没开始执行就发现了：漏冒号、括号不配对、缩进错。
NameError变量未定义
用了没定义过的名字。常见于拼写错误或大小写错（Score 和 score 是两个变量）。
TypeError类型错误
类型不匹配，比如数字和文字相加。"88" + 8 就报这个。数据清洗阶段最常见的错误。
ValueError值错误
类型对但值不合理。int("abc")、数组形状不匹配时会报这个。
IndexError索引越界
访问了不存在的位置，比如访问第 10 个元素但列表只有 5 个。
KeyError键不存在
访问字典里没有的键。df["不存在的列"] 就会这样。数据处理时经常用它来试探有哪些列。
调试debug
找出 bug 的过程。手段：打印中间结果、print(type(x)) 看类型、断点单步执行。
新手技巧：不确定哪里错了，就在那行前面加一行 print("到这里了", 变量)，看它有没有执行到。

⑤ 面向对象 7 个

类class
一类东西的"设计图"。规定这类东西有哪些属性、能做什么。
类比：图纸。「学生」这个类规定了：有姓名、有学号、能考试。
对象 / 实例object / instance
按图纸造出来的具体东西。张三是一个对象，「学生」是类。
属性attribute
对象身上的数据。张三的姓名、高数都是属性。
方法method
对象能做的事。张三能"计算总分"，这就是一个方法 —— 写在类里面的函数。
selfself
方法里代表"调用这个方法的那个对象自己"的参数。第 9 周会卡住你半天的就是它。
类比："我今天很高兴"里的"我"。self.姓名 就是"我.姓名"。
继承inheritance
新类直接获得已有类的属性和方法。省代码，也表达"本质上是同一种东西"。
魔法方法dunder / magic method
名字前后各有两个下划线的方法，让类支持 Python 内置操作。__init__ 管"创建时该做什么"，__str__ 管"打印成什么样子"。

⑥ pandas 核心名词 18 个 —— 教材第 11—12 周的主角

DataFramedataframe
pandas 里的一张二维表，有行索引、有列名。整本书的绝对主角。
类比：Excel 里的一张工作表，但可以存几百万行。
Seriesseries
一列数据，带索引。df["高数"] 取出来就是一个 Series。DataFrame = 多个 Series 拼起来。
index / 索引index
行标签。默认是 0,1,2,3… 也可以改成学号、日期等有意义的东西。
columns / 列名columns
每一列的名字。df.columns 就能看到所有列名 —— 拿到陌生数据的第一步就是看它。
NaNNot a Number
pandas 里表示"缺失值"的特殊值，isnull() 专门找它。注意 NaN != NaN，所以不能直接比较判断。
shapeshape
表的尺寸，返回 (行数, 列数)。df.shape → (8, 9) 表示 8 行 9 列。
locloc
按标签取数据。行用索引名、列用列名：df.loc[0, "高数"]。
记忆法：loc = label（标签）。
ilociloc
按位置取数据，只认整数序号：df.iloc[0, 3] 表示第 1 行第 4 列。
记忆法：iloc = integer（整数位置）。loc vs iloc 是必考的坑。
布尔索引boolean indexing
用一个"真/假"的序列筛出符合条件的行，这是 pandas 筛选的核心机制。
例：df[df["高数"] >= 90] —— 先算出每行"是否 ≥90"，再挑出为真的行。
groupbygroup by
按某列分组，分别做统计。pandas 的命根子，相当于 SQL 的 GROUP BY。
例：df.groupby("专业")["高数"].mean() = 每个专业的平均高数。
聚合函数aggregation
把一堆值压成一个值：sum mean count max min std。
merge / 合并merge / join
把两张表按共同的列拼起来，相当于 SQL 的 JOIN。how="left" 表示以左表为准、右侧缺的补空。
透视表pivot table
Excel 里那个"拖字段自动汇总"的工具，pandas 里是 pivot_table()。
applyapply
对每一行/每一列套用你自己写的函数。功能最强但也最慢，能用别的写法就别用它。
astypeastype
转换数据类型。df["学号"].astype(str)、.astype(int)。数据清洗必用。
describedescribe
一行代码输出所有数值列的统计摘要：个数、均值、标准差、最小、四分位、最大。
缺失值处理missing value
三种常见做法：删掉（dropna）、填值（fillna）、保留并在计算时忽略。选哪种取决于业务，没有标准答案。

⑦ 教材第 3 章：数据处理五步 17 个

数据采集data collection
把数据从各种来源弄到手：文件、数据库、网页、传感器。pandas 里是 read_csv、read_excel、read_sql。
数据质量data quality
数据"好不好用"的综合判断：准不准、全不全、干不干净、及时不及时。
残缺数据incomplete data
该有的值没有 —— 某个人没填年龄、某条记录缺字段。对应 pandas 的 NaN。
处理：fillna(中位数)、dropna()、按业务规则推断填补。
噪声数据noisy data
值本身不合理或错误 —— 年龄填了 250、身高 3000。真实世界常见，且不能靠平均值发现。
处理：设合理范围过滤（df[df["年龄"] < 100]）或视为缺失处理。
冗余数据redundant data
重复的、不提供额外信息的记录 —— 同一个人被登记了两次。
处理：df.duplicated() 找出来，df.drop_duplicates() 删掉。
脏数据dirty data
格式不统一 —— 专业写成 "大数据 "（尾部有空格）、"大数据"、"大 数据"，本质是同一个意思却被当成三组。
处理：df["专业"].str.strip() 去空格、统一大小写/简繁。
数据清洗cleaning
处理残缺、噪声、冗余，让数据"能用"。这是所有数据工作中最花时间的一步，也是第 11 周的核心。
数据变换transformation
把数据改成便于分析的形式：转换类型、重新分档、标准化、算新指标。
属性类型变换type transform
改变数据的类型：文字"88"转成数字 88，日期字符串转成日期类型。astype() 干这个。
属性值变换value transform
值本身变了但类型没变：把分数 88 变成等级"良好"、把 100 分制转成 5 分制。
pandas：pd.cut() 分档、np.where() 条件替换、apply() 自定义。
标准化standardization
把不同量纲的指标拉到同一把尺子上，否则数值大的那个会"压"住小的。
Z-Score：(x - 均值) / 标准差，结果均值为 0、标准差为 1。必须做均值和标准差各减各除那一遍。
数据集成integration
把分散在不同地方的数据合成一张表。merge（按共同列）、concat（上下/左右拼接）。
模式匹配schema matching
合并时确认两张表的结构对得上：字段名一致吗、类型一致吗、主键有重复吗。
实际坑：两边都有"学号"，但一边是 int 一边是 str，merge 会静默匹配失败得到一堆 NaN。
数据值冲突conflict
同一个实体在不同来源里值不一样 —— 这个人在这张表是"大数据"，在那张表是"数据科学"。
处理：定一个"可信来源"优先，或按规则裁决。这是业务问题，不是技术问题。
数据归约reduction
把数据变小以便分析 —— 删掉不用的列，或把多行压成一行汇总。
维归约dimensionality reduction
减少"列"的个数，去掉与分析无关的属性。drop(columns=[...])。目的是去掉噪声。
注意：严格意义上的"降维"是指 PCA 这类数学方法；教材这里只是泛指"减列"。
数值归约numeric reduction
减少"行"的个数，或把多行压成汇总值：groupby().mean()。目的是看清规律。
ETLExtract-Transform-Load
抽取 → 变换 → 加载，数据进数据仓库的标准流程。对应教材的"采集 → 变换 → 集成"。几乎所有数据平台都在讲这个词。

⑧ 统计与机器学习基础 17 个

描述统计descriptive statistics
把一批数据总结成几个数字。均值、中位数、标准差、分位数 —— pandas 的 describe() 就是它。
均值mean
所有数加起来除以个数。会被极端值拉偏 —— 一百个人月薪 5000，一个人 50 万，均值就失真了。
中位数median
排序后位于中间那个数。比均值稳健，不受极端值影响。收入类数据必看中位数。
众数mode
出现次数最多的值。"买什么手机"这种问题的答案。
标准差 / 方差std / variance
衡量数据有多分散。标准差大 = 参差不齐，方差 = 标准差²。教材 1.2 节说数据的有效性时就靠它。
分位数 / 四分位quantile
把数据按大小切成四份：P25、中位数 P50、P75。describe() 输出的 25%/50%/75% 就是它们。
用途：判断分布偏不偏、有没有长尾。成绩、收入、房价数据几乎都右偏（少数特别高）。
离群值outlier
明显偏离整体的极端值。describe() 里 mean 和 std 差距大、或 max 远高于 75%，往往就有离群值。
分类classification
预测"属于哪一类"：垃圾邮件/正常邮件、疾病/健康。
回归regression
预测"是多少"：明天的气温、下个月的销售额。教材 4.2 节的多元线性回归属于这类。
聚类clustering
没有标准答案的情况下，把相似的数据分堆。教材 4.4.1 节的 K-Means 属于这类。
和分类的区别很关键：分类是"有标签的学习"（已知答案是猫还是狗），聚类是"自己发现结构"。
簇 / 簇心cluster / centroid
分出来的一堆叫"簇"，每簇的代表点叫"簇心"。K-Means 里 K 就是簇的数量。
簇内平方和inertia / within-cluster SSE
每个点到所属簇心的距离平方和。越小说明分得越紧、越好。多次运行时用它挑最优结果。
局部最优local optimum
算法停在了"附近最好的解"，但全局还有更好的解。
我的踩坑实录：K-Means 第一版示例只跑出 52.5% 准确率，就是掉进了局部最优。解决办法：多次随机初始化，取簇内平方和最小的那次。算法也有运气成分。
随机种子random seed
让随机数可复现。np.random.seed(42) 之后每次运行结果都一样 —— 调试和写报告时必须加。
混淆矩阵confusion matrix
表格形式对比"真实类别"和"算法预测"。对角线是分对的，其余是分错的。
在我的 K-Means 例子里：运动型 34 对 6 错，学术型 29 对 11 错 —— 一眼看出哪两类容易混。
准确率accuracy
分对的比例 = 分对数 / 总数。我的 K-Means 例子是 85.0%。
注意：准确率高不代表模型好。数据极不平衡时（全对是 1%），猜全部猜对也有 100% 准确率。

⑨ 大数据核心概念 14 个

大数据big data
不是"很大的数据"，而是用一台机器装不下、必须靠多台机器协作处理的数据。这个定义比"大"更准确。
4V 特征Volume/Value/Variety/Velocity
教材 1.2 节的经典框架：Volume 量大、Velocity 速度快（每秒都在产生）、Variety 类型多（文字图片音频）、Veracity 真实性存疑（脏数据）。
顺序记忆法：「多快杂真」，对应 体量 / 速度 / 多样 / 真实性。
分布式distributed
把任务和数据拆开，分给多台机器一起干，最后汇总结果。这是"大数据"的核心手段。
类比：一个人搬100箱货太慢，叫10个人一起搬 —— 就是分布式。
并行计算parallel computing
多个任务在同一时刻同时算。对应你电脑的多核 CPU，也是超算的基础。
虚拟化virtualization
用软件模拟出多台"虚拟电脑"，让一台物理机跑多个系统。云端服务器全靠它。
云计算cloud computing
通过网络租用别人的算力和存储，用多少付多少，不用自己买机器。
相关：Google Colab 免费提供云端 Python 环境，环境坏了不用重装，笔记本也不怕丢。
云存储cloud storage
存在别人服务器上的存储（网盘、对象存储）。和云计算是配套的：算力租用 + 存储租用。
超算supercomputing
成千上万个 CPU 核心同时算的机器，用于气象预报、基因测序、人工智能训练。
Hadoop / HDFSHadoop / HDFS
最经典的开源大数据框架。HDFS 是它的分布式文件系统 —— 专门存超大数据、把文件切成块分散在多台机器上。
MapReducemap reduce
Hadoop 的计算模型：Map 分头发任务 → Reduce 汇总结果。思想极其朴素，但适合海量数据。
Sparkspark
比 Hadoop 快得多的新一代计算引擎，内存计算，用 Python 接口叫 PySpark。
重要：Spark 的 DataFrame 设计几乎是照着 pandas 抄的。你学 pandas 时遇到的坑和直觉，学 Spark 几乎原样复用。
数据仓库data warehouse
为"分析"专门设计的存储系统 —— 存的是清洗整理过的历史数据，结构规范，专供查报表和做分析。
数据湖data lake
什么都往里扔的原始数据仓库，格式不限。数据湖 vs 数据仓库是常见考点：湖是原始的、杂乱的，仓是整理过的、规范的。
单机 vs 集群single machine vs cluster
pandas = 单机内存工具。装得进内存它无所不能，装不进就得换成 Spark。这就是 pandas 的能力边界，也是为什么大数据课程后面要学 Spark。

⑩ 工具与环境 13 个

Anacondaanaconda
一个"全家桶"Python 发行版，自带 numpy、pandas、matplotlib、jupyter 等几百个科学计算库，还自带环境管理器。
为什么推荐给你：数据专业后面要用的库全都在里面，第 11 周开始不用再为装依赖烦恼。官网 anaconda.com。
condaconda
Anaconda 自带的环境/包管理器。conda install xxx。管"环境"和"库"两件事。
pippip
Python 官方的包安装工具。pip install xxx。pip 只管库，conda 还能管环境 —— 这是两者主要区别。
Jupyter Notebookjupyter
网页形式的交互式编程环境：代码分"格"写，一格一格跑，边跑边看结果和图表，还能加文字说明。
为什么数据专业爱用它：写探索性分析太方便 —— 一段代码跑出图，立刻看到，不用等整个程序跑完。写数据报告也是神器。
VS Codevs code
微软的免费代码编辑器，轻快、插件多。装个 Python 插件就能写 Python，还能一键运行和调试。
建议：写"项目型"代码用 VS Code，写"探索型"分析用 Jupyter Notebook。两个都装，各管各的。
PyCharmpycharm
JetBrains 出品，功能最全的 Python IDE。自动补全、调试、代码重构都很强。学生版免费。
终端 / 命令行terminal / CLI
用文字命令操作电脑。装库、切换环境、跑程序都要用。python 文件名.py 就是启动一个程序。
门槛提示：刚开始只用两条命令就够 —— pip install xxx 和 python 文件名.py。其余以后遇到再学。
编码 / 乱码encoding
计算机存文字只认 0 和 1，中文要编码成数字。编码对不上就显示成"锟斤拷"或问号 —— 中文编程第一大坑。
解决方法：读写文件永远加 encoding="utf-8"。Windows 上可能还需要 utf-8-sig。
CSVcomma separated values
逗号分隔的纯文本表格。优点：任何软件都能打开、体积小。缺点：不保存格式和数据类型。
为什么 pandas 默认用 CSV：它是"数据界的 txt"，最通用、交换最方便。Excel 好看但封闭，CSV 丑但开放。
JSONjson
文本格式，结构是"名字: 值"嵌套。本质就是 Python 的字典 + 列表，所以 json.load() 读出来直接就是字典。
用在哪：爬虫抓到的网页数据、API 接口返回、配置文件 —— 几乎全是 JSON。学会它，爬虫就通了一半。
爬虫web scraper
写程序自动从网页上抓取数据。Python 最常用的工具是 requests（拿页面）+ BeautifulSoup（解析 HTML）。
提醒：抓数据前先看网站的使用条款，礼貌抓取、控制频率，别给人添麻烦。
Git / GitHubgit / github
Git 是本地的版本管理工具（记录你每一次修改，可以随时回到任何历史版本）。GitHub 是把 git 仓库放到网上的平台，用来展示作品。
为什么大一就该用：代码写崩了能回退，作业不会丢，而且从第一周就开始积累"作品集"。找工作时是加分项。
数据可视化data visualization
把数据变成图。人眼处理图形比处理数字快几十倍 —— 分析的终点往往是画出一张让人秒懂的图。
工具：Matplotlib（精细控制）、Seaborn（快速出图）、Excel 图表（够用）。

实践题 / 实验exercise / lab

开源软件open source
源代码公开、免费使用和修改的软件。Python、pandas、NumPy 全是开源软件。
对比：Tableau 是商业软件（付费或限功能），pandas 是开源。学校机房如果没装 Tableau，用 pandas 完全等价甚至更强。
可复现reproducible
同样的代码跑出同样的结果。靠固定随机种子 + 把数据来源写清楚实现。
为什么重要：写实验报告时，老师问"这个数是怎么来的"，你能一行代码重跑给他看 —— 这是专业素养的体现。
数据素养data literacy
看到数据能问出好问题、判断数据可不可信、把结论说清楚。比会不会写代码更值钱的能力。
